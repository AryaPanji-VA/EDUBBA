# Phase 15 — Semester 1 Content Expansion v1

Semester 1 is now a genuinely usable multi-course learning library. All seven
official courses have working course pages with real learning content behind
them, built entirely on the shared learning engine proven by Programming
(Variables) and Discrete Mathematics (Propositions). No new learning
infrastructure was built beyond honest generalizations of existing patterns.

## ⚠️ Manual database step (required)

Run these two files manually in the Supabase SQL Editor, in order:

1. `database/phase15-semester1-structure.sql` — adds 6 new modules and 16 new

   the Phase 13.3 ingestion mechanism, diffed against the current database

been run yet (propositions currently loads with 0 sources). It can be run
together with the Phase 15 files.

## Content strategy

Two lesson quality levels:

- **Golden lessons** (existing): Variables (Programming), Propositions
  (Discrete Math) — the deep, architecture-proving reference lessons with
  bespoke components.
- **Standard lessons** (new, 16): a lighter but complete pattern — WHY →
  INTUITION → REPRESENT/SEE → objective interactions with deterministic
  grading → FORMALIZE → Robin Check (lightweight rubric) → CONNECT, plus
  sources, ID/EN localization, mastery, progress, Source Mode, and Learning
  Log. Every lesson makes the learner DO something. No new activity types
  were needed.

## Architecture changes

- **Generic lesson experience.** `lib/lessons/display.ts` maps lesson slug →
  display data (localized activities, content, copy, labels, reinforcement);
  `components/lesson-client.tsx` renders any displayable lesson; dynamic
  routes `app/courses/[courseSlug]/[lessonSlug]` and
  `app/api/lessons/[lessonSlug]` serve every registered lesson with
  registry-trusted course ownership validation. Static golden-lesson routes
  (e.g. `/courses/programming/variables`) keep precedence — existing URLs
  unchanged. A `standardLesson()` factory in the registry removes definition
  boilerplate without changing the registration philosophy.
- **Generic course pages.** `components/generic-course-client.tsx`
  (generalized from the Phase 14B Discrete Math page) + dynamic
  `app/courses/[courseSlug]` and `app/api/courses/[courseSlug]` serve the
  five new courses. No `DesignThinkingCourseClient` etc. — zero bespoke
  course components. Programming keeps its specialized page; discrete-math
  keeps its Phase 14B page.
- **useCurrentLesson multi-course fix.** `defaultCurrentLesson` is derived
  from `implementedLessonSlugsByCourse` (first course with lessons), used by
  both the hook and the server fallback. No hardcoded Programming fallback
  remains (verified by tests).
- **Fake progress removed.** `data/courses.ts` static entries are now
  honest `0% / "Not started"`; `/api/courses` derives real lesson counts
  from the seeded structure and real progress from persisted
  `lesson_progress` completion (local-dev guarded). No invented percentages
  anywhere.

## Learning interactions per subject

All sixteen lessons use the deterministic-first rule: MCQ/predict with
per-answer misconceptions, free-text practice with lesson-owned regex
checkers (accepting ID/EN forms), Robin Check with subject rubrics for
explain-back. Subject-appropriate, not Python-shaped: classify observation
vs assumption (design thinking), attribute failure to the interface (HCI),
trace tables by hand (algorithms), independence/Amdahl scenarios (parallel),
packet/layer reasoning (networking), truth-table evaluation (discrete math).

## Mastery, Smart Feedback, Source Mode, localization

- Mastery: 2–3 concepts per standard lesson (vs 5 in golden lessons), every
  concept with evidence sources; unchanged engine.
- Smart Feedback: lesson-owned rubrics + misconception vocabularies
  (e.g. `linear_pipeline_confusion`, `blame_the_user`, `trace_condition_failed`,
  `dependency_ignored`, `connection_equals_communication`); AI explains after
  deterministic grading only.
- Source Mode: every lesson fully usable without AI (verified by tests).
- Localization: natural conversational ID default + EN, per-lesson modules,
  reusing the shared copy system.
